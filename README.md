# LearnDNS

Biblioteca técnica estática de documentación DNS.

## Archivos
- `index.html`: estructura de la aplicación.
- `styles.css`: identidad visual y diseño adaptable.
- `content.js`: artículos, categorías y glosario.
- `app.js`: navegación, índice por artículo y buscador global.

## Publicación en GitHub Pages
Sube el contenido de esta carpeta a la raíz de la rama configurada para GitHub Pages. No requiere backend ni proceso de compilación.

## Pruebas manuales recomendadas
1. Abrir `index.html` localmente o desde Pages.
2. Abrir cada categoría y artículo desde el menú lateral.
3. Buscar términos que solo aparezcan en el cuerpo, por ejemplo `in-bailiwick`, `MINIMUM`, `NSEC3`, `conditional forwarder` y `pendingDelete`.
4. Probar el índice lateral, los botones de copiar, la navegación anterior/siguiente y el menú móvil.

Los bloques de código y las direcciones IP de documentación utilizan rangos reservados para ejemplos, no endpoints operativos.
